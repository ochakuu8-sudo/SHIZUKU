# SHIZUKU

Godot 4.5 向けの、データ差し替え式ルート分岐育成RPGプロトタイプです。

## 起動

1. Godot 4.5 を開く
2. `project.godot` をインポート
3. `scenes/Main.tscn` またはプロジェクトの実行ボタンで起動

## 入っている機能

- サイコロ(1〜6)を振り、出目の数だけマスを進む本来のすごろく式移動
- 新規ゲームのたびにランダム生成される、桃鉄風のマス目が詰まったグリッド盤面(`scripts/BoardGenerator.gd`)。線が交差・合流する分岐だらけのルートになり、分岐では出目が余っていても必ず足を止めてルートを選択、選んだ後は残りの出目でそのまま進みます
- 横長マップを見渡せるスクロール式マップエリア
- スマホの縦持ち/横持ち両対応レイアウト
- 停止したマスごとのイベント絵/テキスト表示
- 分岐点でのルート選択
- 安全路、鍛錬路、危険路、報酬路、休息路によるルート特性
- 移動ごとのスタミナ消費、危険度、踏破評価
- 危険ルートでは敵が強くなる代わりに戦闘報酬が上昇
- 育成ステータス: 筋力、魅力、知性、覚悟
- HP、スタミナ、ゴールド
- マス効果: 育成、休息、通常イベント、覚悟イベント、戦闘、ボス
- 選択肢つきイベント
- 簡易ターン制バトル
- セーブ/ロード
- 敗北時18+差し替え枠の有効/無効トグル(既定は無効。無効時は敗北しても常にSFWな代替演出を再生します)
- 踏破時の簡易評価(ランク)表示
- これまでに見たイベントを振り返る「回想」ギャラリー
- 新規ゲーム開始時の確認ダイアログ
- サイコロを振る演出、効果音、被弾シェイク/ダメージ数値、HPバーの滑らかな増減などの演出強化
- 出目の数だけマス目を1つずつホップして進む駒(コマ)の移動演出(通過するだけのマスでは育成/イベント/戦闘は発生しません)
- セーブ/ロードは生成された盤面ごと保存/復元するので、ロードしても違う盤面になりません
- 画像素材を使わない手描きベクターアイコン(HP/ST/ゴールド/各ステータス/マス種別)、パネル・ボタンの影による立体感、グラデーション背景など、プロトタイプらしさを抑えた画面デザイン

## ビルド

PC版とWeb版は同じGodotプロジェクトから作ります。

- Web: GitHub Pages向け `Web` export
- PC: Windows向け `Windows Desktop` export

詳しくは `docs/BUILD_AND_DEPLOY.md` を参照してください。

## 素材差し替え

文章と画像は `data/events.json` を編集します。盤面は `New` を押すたびに `data/board.json` の設定(グリッドサイズ、マスの種類の出現比率、ラベル/本文の候補プールなど)に沿ってランダム生成されます。マスの並び自体を手動で1つずつ指定する形式ではなくなったので、盤面の雰囲気を変えたい場合は `data/board.json` の候補プールや重みを編集してください。詳しくは `docs/DATA_GUIDE.md` を参照してください。マップエリアはスクロール式なので、生成された盤面が画面より広くてもそのまま表示できます。

例:

```json
{
  "id": "defeat_slot_custom",
  "category": "defeat",
  "title": "敗北イベント名",
  "body": "ここに用意した成人向け敗北演出",
  "image_path": "res://assets/events/sample.png",
  "adult_only": true,
  "choices": [
    {"label": "記録して拠点へ戻る", "effects": {"resolve": 2, "charm": 1}},
    {"label": "選択肢B", "effects": {"mind": 2}}
  ]
}
```

成人向け素材は、主人公が成人女性である設定の敗北時差し替え枠として扱います。GitHub Pagesは公開URLになるため、公開範囲と素材内容を必ず確認してください。

### フォントについて(読み込み速度)

`assets/fonts/NotoSansCJKjp-Regular.otf` は、フル収録版(約16MB)ではなく、現在のゲーム内テキスト+ひらがな/カタカナ全域+主な記号だけに絞り込んだサブセット版(約360KB)を同梱しています。Web版の配布サイズはこのフォントがほぼ全てを占めていたため、サブセット化により `index.pck` が約14.5MB→約0.4MBまで縮小し、読み込みが速くなっています。

`data/events.json` や `data/board.json` にサブセットへ含まれない漢字を使った場合、`allow_system_fallback=true`(フォントインポート設定)によりOS標準フォントへ自動フォールバックするため文字化けはしませんが、書体がNoto Sans CJKと変わります。同じ書体で揃えたい場合は `tools/subset_font.py` を使ってフォントを作り直してください(フル収録版のNoto Sans CJK JPが別途必要です)。
