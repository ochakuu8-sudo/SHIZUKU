# Data Guide

## `data/board.json`(盤面レイアウト)

盤面は**固定**です。以前はランダム生成していましたが、「分岐が多すぎて選ぶのが面倒」という指摘を受けて、ランダム生成はやめて `board.json` に直接マス目を1つずつ手で配置する方式に戻しました。`New` を押しても常に同じ盤面になります(`GameState.new_game()` はこのファイルをそのまま読み込むだけです)。

盤面は25x25のグリッド座標(`x`, `y`)上に配置しています。開始マス(`start_id`)は座標の**中央**(12, 12)に置き、そこから北(鍛錬路)・南(休息路)・東(危険路、ボスへ続く本筋)・西(報酬路)の4方向へ、まっすぐな本道を9マスずつ伸ばしています(桃鉄のようにマスを格子状に並べつつ、蛇行はさせていないので見た目がわかりやすくなっています)。東の本道の一番奥がボスマスです。

本道だけだと選択肢が開始マスの1回だけになり単調なので、**各方向の本道5マス目に、行き止まりの寄り道(3マス)を1本ずつ**分岐させています。寄り道は本道の進行方向に対して直角に伸びるので、桃鉄のマップのように十字の腕から小さく枝が飛び出す見た目になります。寄り道の先には、その本道とは違う雰囲気のマス(危険/報酬など)を置いていて、寄るかどうかの判断にちゃんと意味が出るようにしています。分岐(選択を迫られるマス)は、開始マス(4方向choice)と各本道の寄り道分岐点(本道を進むか寄り道するかのchoice、4か所)の**合計5か所**です。各マスの `next_ids` は**双方向**のつながり(道)を表します(A の `next_ids` に B があれば、B の `next_ids` にも A があります)。行き止まり(寄り道の突き当たりや各方向の本道の終点)に着いたら自動で引き返します。

**進み方**: 「次へ進む」でサイコロ(1〜6)を振り、出目の数だけ道を辿って進みます。今いるマスに複数の道があっても、直前に来た道を戻るだけなら自動でまっすぐ歩き続けます。直前に来た道を除いても2方向以上に進める分かれ道に着くと、出目が余っていてもそこで足を止め、**プレイヤーが自分でどちらに進むか選びます**(来た道を戻る選択肢も含めて自由に選べます)。選ぶと、余っていた出目はそのまま消化されて選んだ先へ進み続けます。行き止まり(道が1本しかなく、それが今来た道だけ)に入り込んだ場合は、来た道を引き返しながら残りの出目を消化します。ボスマスは、出目がいくつ余っていても必ずそこで足を止めて戦闘になります。

サイコロの出目で通過しただけのマス(足を止めなかったマス)では、育成/イベント/戦闘などのマス効果は発生しません(移動コストや危険度の変化はマスごとに発生します)。実際に足を止めたマスでだけ、マス効果とイベント絵/テキストが再生されます。

セーブデータには盤面自体も一緒に保存されます。ロードすると、セーブ時と同じ盤面に復元されます(将来 `board.json` の中身を差し替えても、古いセーブは当時の盤面のまま遊べます)。

### `board.json` の構造

```json
{
  "width": 25,
  "height": 25,
  "start_id": 0,
  "spaces": [
    {
      "id": 5,
      "x": 12,
      "y": 7,
      "type": "train",
      "label": "書庫",
      "description": "静かに書物と向き合い、知見を広げる。",
      "stat": "mind",
      "next_ids": [4, 6, 10]
    }
  ]
}
```

上の例は北の本道5マス目にある分岐点で、`next_ids` が3つ(本道の手前・本道の奥・寄り道の入口)あるので分岐になります。

- `width` / `height`: マップ表示用のグリッドサイズの目安(スクロール範囲の計算に使います)。マスの実際の並びは各マスの `x` / `y` で決まります。
- `start_id`: 開始マスの `id`。
- `spaces[]`: マス1つ1つの定義。**マスを増減・並べ替えしたい場合は、この配列を直接編集します**。
  - `id`: マスの一意な番号。`next_ids` から参照されます。
  - `x` / `y`: マップ上の表示座標(グリッド座標)。
  - `type`: `start` / `boss` / `train`(育成) / `event`(イベント) / `encounter`(戦闘) / `rest`(休息) / `shop`(ショップ) のいずれか。
  - `label` / `description`: マスの見出しと本文。
  - `next_ids`: そのマスから道がつながっている隣接マスの `id` の配列(**双方向**。両端のマスの `next_ids` に互いの `id` を入れること)。ここに3つ以上 `id` が並んでいるマスが「分岐」になります。
  - `stat`(`type: "train"` のみ): 伸びるステータス(`str`/`charm`/`mind`/`all`)。
  - `category`(`type: "event"` のみ): `data/events.json` で使うイベントカテゴリ(`daily`/`resolve`/`story`)。
  - `strong`(`type: "encounter"` のみ): `true` なら強敵ルート、`false` なら通常の遭遇。
  - `route_profile` / `route_label`(任意): そのマスに立ち止まったときに適用するルート特性(`safe`/`training`/`danger`/`reward`/`recovery`。省略時は特性なしの `balanced`)。分岐の先に付けておくと、選択肢のボタンにルートの雰囲気が表示されます。

盤面のマス数や分岐の数・位置を変えたい場合は、`spaces` 配列を直接編集してください。`next_ids` を編集するときは、必ず両端のマスに互いの `id` を追加し(片方向のリンクにしない)、スタートから全マスに辿り着けることを崩さないよう注意してください。

## `data/events.json`

イベント本文、画像、選択肢、効果を定義します。

`adult_only: true` のイベントは、ゲーム画面右上の `18+素材` が有効な時だけ抽選されます。現在の前提では、成人向け素材はマップ上の通常マスではなく、敗北時の `defeat` カテゴリで再生します。

使える `effects`:

- `str`: 筋力
- `charm`: 魅力
- `mind`: 知性
- `resolve`: 覚悟
- `hp`: HP
- `stamina`: スタミナ
- `gold`: ゴールド
- `max_hp`: 最大HP
- `max_stamina`: 最大スタミナ

## `data/enemies.json`

敵データを定義します。

- `hp`: 敵HP
- `attack`: 敵攻撃力
- `reward_gold`: 勝利時ゴールド
- `reward_resolve`: 勝利時覚悟
